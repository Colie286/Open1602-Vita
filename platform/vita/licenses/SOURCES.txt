# Vita distribution notices

The VPK includes the project GPL-3.0 text, ENet and Lua MIT notices, SDL3 and
zlib notices, dav1d and Opus BSD notices, and `ThirdParty.txt` for the remaining
linked components. dav1d and Opus sources and COPYING files are included under
`third_party/`, as imported by Open1602 0.5.0 (62a3683f029322ea67a74282bffba6f4ba38dc9d).
Original file headers and upstream attribution must remain in source releases.

`ThirdParty.txt` preserves the notices from stb_vorbis and dr_flac, the LGPL-2.1
text for the FFmpeg-derived video/audio code, the GCC runtime exception, and the
installed SDK components listed below. Newlib's collection contains notices for
many targets; including the collection does not mean every target is linked.

Publishing the notices alone does not replace source-distribution obligations.
A binary release needs the matching port sources and build scripts, the SDL3
patches, and access to the corresponding library sources. The statically linked
LGPL components, including pthread-embedded, also require a relinkable source
arrangement. Keep the pinned sources available alongside the release; do not
rely solely on an old or private source repository or a moving upstream branch.
